# CineBook - Movie Booking UI

## Project Overview

CineBook is a modern movie ticket booking interface created as part of the UI Template Collection Hackathon.

The project demonstrates a complete movie booking flow:

Home → Movies → Movie Details → Seat Selection → Booking Confirmation

## UI Pattern

Movie Ticket Booking / Entertainment Platform

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Main Features

- Modern cinematic dashboard
- Trending movie section
- Movie search
- Movie details page
- Seat selection
- Booking confirmation
- My Bookings page
- Dark/Light mode
- Cursor glow effect
- Hover animations
- 3D card tilt effect
- Responsive design
- LocalStorage based booking data

## Pages

### index.html

Main CineBook dashboard.

### movies.html

Displays available movies and provides movie search.

### movie.html

Displays movie information and starts the booking process.

### seats.html

Allows users to select available seats.

### bookings.html

Displays the confirmed booking.

## Booking Flow

1. Open CineBook.
2. Select Movies.
3. Choose a movie.
4. Click Choose Seats.
5. Select available seats.
6. Confirm booking.
7. View the booking under My Bookings.

## LocalStorage

JavaScript LocalStorage is used to store:

- Selected movie
- Selected seats
- Booking details
- Theme preference
- Login information

## Design

The interface uses:

- Dark cinematic background
- Gradient accents

## Research

Movie booking platforms commonly use:

- Movie discovery
- Search
- Ratings
- Movie details
- Theatre selection
- Showtime selection
- Seat selection
- Booking confirmation

CineBook implements these patterns with an original interface and interaction flow.
