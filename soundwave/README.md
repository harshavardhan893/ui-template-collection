# SoundWave - Music Streaming UI

## Project Overview

SoundWave is an original music streaming user interface inspired by modern music platforms.

The project demonstrates how a modern music application can be designed using HTML, CSS and JavaScript.

## UI Pattern

The main UI pattern is a Music Streaming Dashboard.

It contains:

- Sidebar navigation
- Music cards
- Search interface
- Playlist management
- Music player
- Recently played section
- Liked songs
- Responsive layout

## Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Features

The project uses JavaScript for:

- Music player controls
- Search
- Playlist management
- Liked songs
- Progress simulation
- Volume settings
- Theme settings
- Toast notifications

## LocalStorage

The application stores:

- Liked songs
- Playlist songs
- Current song
- Theme
- Volume

This allows user selections to remain after refreshing the page.

## Design Features

The interface includes:

- Dark modern theme
- Green accent color
- Gradient album artwork
- Hover effects
- Cursor glow
- Animated vinyl record
- Responsive design
- Interactive buttons
- Fixed music player

## How To Run

Open:

index.html

in a web browser.

No server is required.

## Research / Design Observation

Modern music streaming applications commonly use:

- Persistent sidebar navigation
- Album artwork cards
- Search and discovery
- Personalized playlists
- Persistent music controls
- Dark interfaces
- Responsive layouts

SoundWave implements these patterns with an original visual design.
