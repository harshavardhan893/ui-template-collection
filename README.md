# 🎨 UI Template Collection Hackathon

A collection of modern, responsive and interactive UI templates built using HTML, CSS and JavaScript.

## 🚀 Applications

### 🍔 QuickBite
A food delivery interface inspired by modern food ordering applications.

Features:
- Restaurant browsing
- Food menu
- Search
- Cart
- Orders
- Favorites
- Responsive design

### 🎬 CineBook
A movie discovery and ticket booking interface.

Features:
- Movie browsing
- Movie details
- Seat selection
- Ticket booking
- My Bookings
- Search
- Responsive design

### 🎥 StreamFlix
A movie streaming interface inspired by modern streaming platforms.

Features:
- Trending movies
- Popular movies
- Search
- Watch page
- My List
- Responsive design

### 🎵 SoundWave
A modern music streaming interface.

Features:
- Music search
- Playlists
- Music player
- Like songs
- Add to playlist
- Volume controls
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
