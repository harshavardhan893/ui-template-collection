# StreamFlix - Streaming UI Template

## Project Overview

StreamFlix is a modern streaming-platform UI template created for the UI Template Collection Hackathon.

The project demonstrates a streaming application interface with movie discovery, watch pages and a personal movie list.

## UI Pattern

Streaming / Entertainment Platform

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Cinematic home dashboard
- Trending content
- Popular movies
- Movie search
- Watch page
- My List
- Add/remove movies
- Dark/light mode
- Cursor glow effect
- Hover animations
- Responsive layout
- LocalStorage support

## Pages

### index.html

Main streaming dashboard.

### movies.html

Movie discovery and search page.

### watch.html

Movie watching interface.

### mylist.html

Personal saved movie list.

## User Flow

Home → Movies → Search → Watch → Add to My List

## LocalStorage

The application stores:

- Selected movie
- My List movies
- Theme preference

## Design

The interface uses a cinematic dark theme, large hero content, movie cards, gradients, hover effects and responsive layouts.

## Research

Common streaming interfaces use:

- Large featured content
- Categories
- Movie cards
- Search
- Continue watching
- Personal lists
- Ratings
- Watch pages

StreamFlix implements these patterns with an original interface.

## How to Run

Open `index.html` in a browser.

No external dependencies are required.

## Hackathon Contribution

StreamFlix contributes a complete streaming-platform UI template to the UI Template Collection.
