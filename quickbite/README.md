# 🍔 QuickBite

## UI Template Collection Hackathon

QuickBite is an original food-delivery UI template inspired by modern
food ordering applications.

The project demonstrates responsive web design, interactive components,
animations, local browser storage and a multi-page user experience.

---

## 👨‍💻 Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

No external frameworks are required.
